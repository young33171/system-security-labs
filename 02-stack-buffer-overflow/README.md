# Stack & Buffer Overflow

## 학습 내용

- 함수 호출과 스택 프레임
- 지역 변수, 매개변수, 저장된 프레임 포인터, 반환 주소
- 버퍼 경계를 벗어난 메모리 접근
- 메모리 보호 기법: NX, ASLR, Stack Canary, PIE

## 실습 파일

수업에서는 `stack_example.c`, `buf_ret.c` 등을 사용해 함수 호출 시 스택 메모리의 변화를 살펴봤습니다.

## 핵심 개념

스택에는 함수 실행에 필요한 지역 변수와 반환 주소 등이 저장됩니다. 배열의 범위를 벗어난 쓰기가 발생하면 인접한 메모리 값이 변경될 수 있습니다. 이를 방지하기 위해 경계 검사와 컴파일러 보호 옵션을 함께 적용해야 합니다.

## 분석 포인트

1. 함수 호출 전후 스택 포인터 변화
2. 지역 변수의 메모리 배치
3. 버퍼 크기와 쓰기 범위 비교
4. 보호 옵션 적용 전후 차이
